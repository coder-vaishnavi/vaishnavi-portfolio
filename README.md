# Vaishnavi Portfolio 🚀

Personal portfolio website built with **React, Tailwind CSS, and Vite** to showcase my skills, projects, achievements, and journey in **AI/ML & Data Science**.

🌐 **Live:** https://vaishnavi-portfolio-kohl.vercel.app/

## 🛠️ Tech Stack

* React.js
* Tailwind CSS
* Vite
* JavaScript
* Vercel

## 🚀 Run Locally

```bash
npm install
npm run dev
```
